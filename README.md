# NovaRetail+ | Análisis de comportamiento de clientes

## Descripción del proyecto

Proyecto de análisis exploratorio y estadístico de datos enfocado en identificar relaciones y patrones en el comportamiento de los clientes de NovaRetail+, con el propósito de generar información útil para la toma de decisiones de negocio.

## Objetivo

Analizar las variables relacionadas con el comportamiento de los clientes para identificar posibles factores asociados con sus compras, nivel de gasto, satisfacción y abandono.

## Herramientas y tecnologías

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Desarrollo del análisis

El proyecto incluyó las siguientes etapas:

1. **Exploración y preparación de datos:** revisión de la estructura, tipos de variables y calidad del conjunto de datos.
2. **Análisis exploratorio:** evaluación de distribuciones y características de las variables numéricas y categóricas.
3. **Análisis de correlación:** aplicación de los métodos Pearson y Spearman para identificar relaciones entre variables numéricas.
4. **Análisis estadístico:** evaluación de asociaciones entre variables y exploración de posibles relaciones engañosas.
5. **Visualización:** elaboración de gráficos de dispersión y matrices de correlación para facilitar la interpretación de resultados.
6. **Interpretación:** documentación de hallazgos, supuestos y limitaciones, con formulación de recomendaciones de negocio.

## Principales habilidades demostradas

- Análisis exploratorio de datos (EDA).
- Limpieza y preparación de datos.
- Análisis estadístico y correlación.
- Visualización de datos.
- Interpretación de resultados.
- Comunicación de hallazgos y recomendaciones de negocio.
